# Список крупных задач для систем

## Сервис управления ставками
1. Разработка API для получения актуальных ставок по депозитам
2. Реализация механизма формирования файлов со ставками в согласованном формате
3. Разработка компонента для автоматической выгрузки файлов на SFTP-сервер
4. Внедрение механизма уведомлений об изменении ставок

## SFTP-сервер
1. Развертывание SFTP-сервера в инфраструктуре банка
2. Настройка безопасного доступа и аутентификации
3. Настройка мониторинга и аварийного оповещения
4. Настройка автоматической очистки устаревших файлов

## Система кол-центра банка
1. Разработка интеграции с API сервиса управления ставками
2. Модификация интерфейса для отображения актуальных ставок
3. Внедрение кэширования данных для снижения нагрузки на API
4. Обработка ошибок при недоступности API

## Система партнёрского кол-центра
1. Разработка компонента для получения файлов с SFTP-сервера
2. Интеграция данных о ставках в интерфейс системы
3. Реализация механизма автоматического обновления данных
4. Внедрение контроля версий файлов для предотвращения использования устаревших данных
