# FURPS+ Требования

## Функциональные (Functionality)

| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| F1  | Отображение списка доступных депозитов с актуальными ставками на сайте |  |
| F2  | Подача заявки на депозит на сайте с указанием телефона и ФИО |  |
| F3  | Отображение в интернет-банке списка доступных депозитов с актуальными и персонализированными ставками |  |
| F4  | Возможность указать счет и сумму депозита и подать заявку в интернет-банке |  |
| F5  | Подтверждение операции открытия депозита с помощью SMS-кода |  |
| F6  | Обработка заявок сотрудниками бэк-офиса в АБС |  |
| F7  | Отправка SMS-уведомлений клиентам после подтверждения ставки и открытия депозита |  |
| F8  | Система управления ставками по депозитам для сотрудников бэк-офиса |  |

## Удобство использования (Usability)

| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| U1  | Соответствие интерфейсов принятой в компании системе дизайна |  |
| U2  | Использование брендированных элементов и фирменных цветов |  |
| U3  | Удобный и интуитивно понятный интерфейс для процесса подачи заявки |  |

## Надёжность (Reliability)

| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| R1  | Доступность сервисов 24/7 с показателем 99,9% |  |
| R2  | Устойчивость к сбоям в ЦОД через переключение на резервный ЦОД |  |
| R3  | Корректная обработка ошибок с информированием пользователей |  |

## Производительность (Performance)

| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| P1  | Время отклика по всем операциям должно быть в миллисекундах |  |
| P2  | Время загрузки справочных данных менее 1 секунды |  |
| P3  | Равномерное горизонтальное масштабирование и распределение запросов |  |
| P4  | Минимизация нагрузки на базу данных АБС |  |

## Поддерживаемость (Supportability)

| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| S1  | Использование существующих технологий (MS SQL, Oracle) |  |
| S2  | Совместимость новых технологий с существующими платформами |  |
| S3  | Предпочтение технологиям, в которых у сотрудников банка есть экспертиза |  |
| S4  | Разработка документации для дальнейшего расширения системы |  |
| S5  | Подготовка к переходу на микросервисную архитектуру для интернет-банка |  |

## + Ограничения (Restrictions)

| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| +R1 | Несовместимость текущей версии интернет-банка с Kafka |  |
| +R2 | Ограничение по вертикальному масштабированию АБС |  |
| +R3 | Защита чувствительных данных механизмом шифрования трафика |  |
| +R4 | Избегание прямой интеграции интернет-банка с API АБС |  |
| +R5 | Необходимость личной идентификации новых клиентов в отделении |  |
